# Subtitle Fonts Directory

This directory is reserved for local packaging of licensed subtitle font assets for the ClipIt ASS/FFmpeg video rendering pipeline:

- `Impact.ttf` (Default Viral & Bold font)
- `Montserrat-Bold.ttf` (Clean & Cinematic)
- `BebasNeue-Regular.ttf` (Tall Condensed)
- `ArialBlack.ttf` (Heavy Punchline)
- `Cinzel-Bold.ttf` (Cinematic Drama)
- `KomikaAxis.ttf` (Comic & Hinglish Humor)
- `Rubik-Black.ttf` (Gaming & High Energy)

During the UI preview stage, Flutter falls back to standard bundled system fonts. Production rendering fonts will be copied and registered here prior to packaging.
